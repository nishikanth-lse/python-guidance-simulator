# Changelog

All notable changes to this project will be documented in this file.

The format follows the principles of Keep a Changelog and Semantic Versioning.

---

## [1.0.0] - 2026-07-09

### Added

* Initial public release.
* Two-dimensional drone dynamics.
* Modular PID controller implementation.
* Independent X and Y control loops.
* Figure-eight trajectory generation.
* Wind disturbance model.
* Interactive parameter tuning.
* Performance metrics (RMSE, average error, maximum error).
* Trajectory visualization.
* Matplotlib-based animation.
* Google Colab compatibility.
* Project documentation.
* Example trajectory implementations.

### Changed

* Refactored the original educational simulation into a modular architecture.
* Improved code organization and readability.
* Separated simulation components into reusable classes.

### Planned

* Additional trajectory generators.
* Waypoint navigation.
* Aerodynamic drag model.
* Three-dimensional dynamics.
* ROS 2 integration.
* PX4 SITL compatibility.
* Extended Kalman Filter.
* Multi-agent simulations.
