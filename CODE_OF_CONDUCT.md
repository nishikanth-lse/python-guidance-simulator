# Code of Conduct

## Our Commitment

This project aims to provide a welcoming, respectful, and collaborative environment for everyone, regardless of experience level, background, or identity.

We encourage constructive discussion, knowledge sharing, and professional collaboration.

## Expected Behavior

Contributors are expected to:

* Be respectful and considerate in all interactions.
* Provide constructive feedback during discussions and code reviews.
* Assume good intent when reviewing contributions.
* Keep discussions focused on improving the project.
* Respect differing technical opinions and approaches.

## Unacceptable Behavior

The following behaviors are not acceptable:

* Harassment, discrimination, or personal attacks.
* Offensive or inappropriate language.
* Deliberate disruption of discussions or development.
* Publishing private information without consent.
* Any conduct that negatively impacts the collaborative environment.

## Scope

This Code of Conduct applies to:

* GitHub Issues
* Pull Requests
* Discussions
* Project documentation
* Any other official communication channels related to this repository

## Reporting

If you encounter behavior that violates this Code of Conduct, please open a private discussion with the project maintainer or submit a confidential report through GitHub.

Reports will be reviewed fairly and handled with appropriate discretion.

## Enforcement

Project maintainers reserve the right to edit, remove, or reject contributions and discussions that violate this Code of Conduct.

Repeated violations may result in temporary or permanent removal from the project community.
